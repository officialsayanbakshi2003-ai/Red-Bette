# Image prompts for Red Betta

Use these prompts in any AI image generator (Midjourney, Ideogram, Leonardo, Firefly, Higgsfield, etc.). Upload the results from the admin dashboard:

- **Storefront images** (banners and lifestyle): **Admin → Storefront**
- **Product photos**: **Admin → Products → (product) → Images**

**Tips**
- If your tool accepts a reference image, upload your own hoodie mockup so the print matches the real product exactly.
- Add the style line below to every prompt so all images feel like one campaign.
- Avoid text in images; the website adds all text itself.
- Export JPG or WebP, under 5 MB.

**Style line (append to every prompt)**
> dark cinematic streetwear editorial, deep black tones, crimson red (#E3141B) accent light, high contrast, subtle 35mm film grain, shot on a full-frame camera with a 50mm lens, ultra detailed fabric texture, no text, no logos, no watermark
