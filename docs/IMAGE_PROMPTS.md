# Image prompts for Red Betta

Every product and banner image on the site should be a real photo or an AI image generated from these prompts. Upload them from the admin:

- **Product photos:** Admin → Products → open the product → Images → Upload. The first image is the main photo; the second shows when a shopper hovers.
- **Banner and lifestyle photos:** Admin → Storefront.

## Rules for every image
- **Size:** portrait **4:5, 1600 × 2000 px** (banners marked 16:9 are 2400 × 1350 px).
- **Format:** JPG or WebP, under 5 MB.
- **No text or logos** in the image. The site adds all text. AI tools misspell words, so if a print needs lettering, use your real artwork as a reference image instead.
- **Same look everywhere:** add this style line to the end of every prompt.

> **Style line:** dark cinematic streetwear photography, deep black tones, crimson red (#D8121A) accent light, high contrast, subtle film grain, full-frame camera, 50mm lens, ultra detailed heavyweight cotton texture, no text, no logos, no watermark

**Tip:** if your AI tool accepts a reference image, upload your hoodie mockup so the print on the generated photo matches the real product exactly.
